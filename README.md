# 🛡️ Security Toolkit - أداة الأمان للويندوز

أداة خفيفة ومفتوحة المصدر لنظام ويندوز تساعدك على مراقبة اتصالات الشبكة، فحص سلامة الملفات، ومراجعة إعدادات الحماية الأساسية في جهازك بواجهة عربية سهلة.

## ✨ المميزات الرئيسية
* **مراقب الشبكة والاتصالات:** عرض البرامج المتصلة بالإنترنت مع تنبيه فوري عند وجود اتصالات من مسارات أو منافذ مشبوهة، وإمكانية إنهاء العملية المحددة مباشرة.
* **فحص بصمة الملفات (Hash):** حساب البصمة الرقمية (`SHA-256` و `MD5`) لأي ملف للتحقق من سلامته وعدم التلاعب به.
* **فحص أمان النظام:** التحقق السريع من حالة حماية Windows Defender وتفعيل التحكم بحساب المستخدم (UAC) وصلاحيات المسؤول.

## 📥 طريقة التحميل والتشغيل
1. توجه إلى قسم **[Releases](../../releases)** في هذه الصفحة.
2. حمّل ملف **`SecurityToolkit.exe`**.
3. شغّل البرنامج مباشرة (يُفضل التشغيل كمسؤول **Run as administrator** لعرض كافة اتصالات الشبكة).

## ⚠️ تنبيه مهم
هذه الأداة مصممة للمساعدة في الفحص والمراقبة السريعة، **ولا تُعد بديلاً** عن برامج مكافحة الفيروسات (Antivirus) المعتمدة.
